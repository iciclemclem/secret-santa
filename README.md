# Secret Santa V5.3

Cette version 5.3 apporte :

- la **suppression du message** « Ton ticket est découvert et le restera à ta prochaine visite ! » ;
- une **zone révélée recentrée** sur le ticket ;
- un **seuil de grattage à 90 %** avant révélation complète ;
- un **logo sablier** sur la page participant quand le tirage n'a pas encore été effectué ;
- une **animation de fin enrichie** avec confettis + feux d'artifice ;
- un **arrière-plan hivernal amélioré** avec neige et forêt enneigée discrète.

## Démarrage local

```bash
node server.js
```

Variables utiles :

- `HOST`
- `PORT`
- `DATA_DIR`

## Mise à jour depuis la V5.2

Remplace dans ton dépôt GitHub :

- `server.js`
- `package.json`
- `public/app.js`
- `public/style.css`

Conserve le volume Railway `/data`.
